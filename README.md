# 💻 Portfólio Pessoal

Site profissional desenvolvido com **HTML, CSS e JavaScript** para apresentar meu perfil, projetos e formas de contato.

O projeto também consome a **API do GitHub** para exibir informações do perfil e repositórios dinamicamente.

## ✨ Funcionalidades

- Apresentação profissional
- Listagem dinâmica de projetos do GitHub
- Carrossel de projetos com Swiper.js
- Formulário de contato com validação
- Página de confirmação de envio
- Navegação suave
- Layout responsivo para desktop, tablet e mobile

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- Swiper.js
- GitHub API
- FormSubmit
- Render

## 🎯 Objetivo

Criar uma apresentação profissional utilizando tecnologias fundamentais do desenvolvimento web, com integração a APIs e foco em responsividade e experiência do usuário.
